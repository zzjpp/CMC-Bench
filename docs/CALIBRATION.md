# 八层结构难度与校准

本数据集按知识深度、计算负担、推理跨度、方法发现、证明严格性共同判断完整解题难度。年份、数学/非数学组、预赛/决赛均不能直接替代等级。

| 层级 | 判定要求 | 锚题 |
|---|---|---|
| L1 直接应用 | 一个定义、公式或局部观察，计算链短 | 2014预赛非数学I-1：由解确定常系数方程 |
| L2 常规计算 | 方法明确，完成若干计算或常规变换 | 2018预赛非数学I-4：三角乘积极限 |
| L3 多步应用 | 选择并衔接多个常规步骤，检查条件 | 2016预赛数学I：椭球平行光切点 |
| L4 综合推理 | 组合知识点、引入辅助量或控制误差 | 2018届决赛高年级I-4：正交矩阵子块范数 |
| L5 关键技巧 | 明显的方法发现门槛，核心观察后仍需论证 | 2013届决赛高年级V：微分方程比较原理 |
| L6 深入证明 | 较长证明链、边界处理或非平凡最优性论证 | 2014预赛数学V：矩阵多项式方程 |
| L7 复杂构造与综合 | 多层分类、构造或跨方法组合 | 2018届决赛高年级III：数量矩阵与两幂零矩阵分解 |
| L8 高阶挑战 | 高阶理论与非直接构造结合，含锐界、反演或全局论证 | 2017届决赛高年级III：中心交换子与同时三角化 |

高阶知识本身不自动等于L8。集券期望、球面上对称积分即使出现在高年级决赛，也只标为L2或L3。多问任务按完整完成要求判断，不拆后续问抬高样本数。子块计数题按其短证要求标为L4。

每题在difficulty_annotation.rationale保存知识点和方法证据；部分题另有axes文本描述。等级是单个代理的序数判断，不是五维分数加总的量表。允许相邻一级变化；高层可能有两级不确定性。

同时提供四个粗层：L1–L2、L3–L4、L5–L6、L7–L8。八级便于诊断，四个粗层用于检查结论对标签扰动是否稳健。层级不强行等量采样；最高层样本少，必须报告分母。

## 真实校准步骤

1. 两位数学专家独立核对原题、完整原解、评分点与等级，保留分歧和裁定。
2. 在开发集固定多个不同能力档的模型版本、提示、预算、工具权限与重复次数。不能用一次失败定义难题。
3. 若研究学生难度，另收集大学生的课程背景、解题时间与作答；模型成功率不能冒充学生难度。
4. 分别报告指定模型面板和学生群体的成功率、区间和样本量。与数据冲突时修订结构等级并发布新版本，不为维持八层捏造经验阈值。
5. 数据充足后再考虑IRT、拟合与跨群体稳定性。同一模型的重复不是多个独立学生。
6. 调参、选模型只用dev/validation。test用于修改题库或方法后，正式比较须换独立测试材料。

本次未执行真实作答校准：所有empirical_success_rate=null、empirical_sample_size=0、human_reviewers=[]。八层是可审查的初始标注，不宣称已验证的客观难度。

所有评测须绑定题面、参考解答、评分点、等级与划分的内容哈希。错误或歧义题隔离，不计为模型能力失败。
