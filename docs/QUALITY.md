# 来源与数学质量

333道题均有完整题面、来源页码、评分标准及写入JSON的完整参考推导。reference_solution_format统一为inline_full_solution。历史原解通过solution_source保留，pages_one_based定位到相关题目的物理页，作为来源材料；JSON推导可以采用不同且正确的证明。

sources/manifest.json统一保存138份PDF的路径、URL、页数、SHA256及来源类型。社区原卷转载保留上游路径与Git blob标识。来源身份与数学正确性分别处理，不把哈希一致称为官方认证。sources/coverage.json区分归档材料与实际计分题。

## 去重与划分

独立填空子题可单列；相依证明子问整体保留。9处跨卷同题或实质重叠任务合并后只计规范版本一次。所有关联试卷在划分前并组；同一试卷、已确认重复任务族均不跨dev/validation/test。语义近重复仍需数学审阅，题面哈希仅用于检测完全重复。

## 隔离材料

qa/exclusions.json记录不计分的错误或排版歧义题。ARC116 VI所获版本写周期2、3即可推出常数，但sin(2πx)为反例；ARC066 I-2的指数/乘法排版归属不能可靠判断。这些条目不进入333题、划分或模型输入，原材料仅用于回查。

## 核查状态

qa/math_audit.json包含45项精确或符号抽查，覆盖积分、矩阵行列式、递推、构造、三阶Runge–Kutta参数族与边界常数。它们不替代333道完整证明的人工认证。程序测试检查数据与评分工具，不代表数学真值认证。

qa/solution_review.json记录完整解答覆盖数和必要的题面/解答规范化说明。推导已按原卷及原解进行单代理数学核查；原解出现的缺漏不直接照抄。例如最优逼近按题面限定的多项式次数求解，Runge–Kutta问题包含退化参数族。几处隐函数条件显式化，说明保留在对应题目的notes内，不将其额外条件隐瞒于解题者。

自动评分使用两次独立提示审阅同一回答。评分点、严重错误标志、完整正确标志必须一致才能记为automatic_agreement。两次模型判断可能共享错误，故该状态始终是暂定评分；发现参考或题面疑问将进入needs_review。无需等待人工认证即可进行探索性测试，正式认证需另行双专家审阅。

参考形式、原卷条件与等价规范化应一起审阅。评分允许其他正确解法，不能把参考中的更强结论额外要求于解题模型。缺失条件、歧义、错误题应先隔离，不能作为模型能力失败。

所有难度为单代理结构标签，尚无人类或模型作答数据校准，亦未完成双数学专家认证。公开原题及原解可能存在预训练暴露；实验须报告这些限制。
