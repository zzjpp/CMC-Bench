# 评测与评分协议

## 两种独立赛道

1. `closed_book`：只有中文题面，可选原题图形，不允许联网、检索原题、读答案库或执行工具。
2. `tool_assisted`：固定并登记 CAS/Python 等工具的名称、版本、调用次数和资源上限；不允许检索原题或访问参考解答。与闭卷赛道分开报告。

直接解题、同模型自检、不同角色协作等方法如作比较，应在**同一题集、同模型版本、同工具权限、同总预算**下运行。记录全部模型调用、所有角色的输入/输出与推理 token（服务支持时）、工具调用、失败和时间。多角色方法的预算是各角色之和，不能将其额外计算隐藏。注册主预算后，另报告性能—成本曲线。

默认准备请求的每题输出上限为8192 token，只是便于接入的默认值，并未执行或认定为最优预算。不同API对推理token和输出token的计量可能不同，实际运行清单必须写清。温度、随机种子、并发、超时和重试政策均在运行前固定。

每题每次运行仅提交一个最终回答。基础报告为一次运行的完整正确率；多次独立重复应逐次完整评测并报告均值与波动，不得从多次生成里事后挑最好的一次当作 pass@1。若另报 pass@k，必须公开候选数、抽样方式及额外成本。

## 参考解答形式

333题均以inline_full_solution在JSON内提供完整参考推导。solution_source仅用于回查原解、原题号、局部物理页及哈希，不需要PDF解析才能评分。允许与参考不同的正确证明；参考本身若存在数学错误，必须复核，不能以错误参考惩罚正确回答。

自动运行方法见[AUTO_EVALUATION.md](AUTO_EVALUATION.md)。auto_evaluate汇总两次独立LLM评分，结果明确标为automatic_provisional_not_human_adjudicated；evaluate只汇总双人审阅后的人工裁定，二者不能混用。

## 数学评分

各题满分4分，具体评分点见 `scoring_rubric`。允许不同的正确解法，评分点按等价数学内容给予相应分数；不可只因证法不同扣分。

| 总分 | 一般含义 |
|---:|---|
| 4 | 最终结论及所需计算/证明均正确完整，覆盖全部子问 |
| 3 | 主要思路正确，有局部可直接修补的遗漏，尚未达到完整正确 |
| 2 | 有实质进展，但关键步骤缺失或存在影响结论的错误 |
| 1 | 少量正确事实或初步工作，核心任务未完成 |
| 0 | 无有效进展、错误结论、无回答或无法评估的输出 |

最终得分为评分点得分之和；权重为1或2，不用模糊的整体印象覆盖逐点评分。出现支撑结论的严重数学错误时总分至多2分。数值实验、有限个例和CAS输出不能替代题目要求的一般性证明。正确答案配错误推导也不算完整正确。

模型超时、空回答等解题运行失败计0分，并保留相应记录；评分接口失败、两次评分分歧或参考疑问保持“待复核”。自动流程对缺答显式补零，并报告待复核项从0至满分的保守边界；分母始终为整份划分题数。人工裁定汇总对缺题报错，避免只统计成功回答导致分母缩水。

正式人工裁定由两位数学背景评审独立评分，对方法名称盲化，分歧由第三位裁定或两位共同复核并留记录。自动探索性评分可以直接运行，但不能冒充两位人类评审；若声称双专家认证，需真实完成该复核。`reviewer_ids` 是记录声明，程序不能核验评审者身份，真实审核责任由实验负责人承担。

## 评分文件

每行包含一道题的最终裁定。下面仅为**格式说明，未发生任何真实评审或模型运行**：

```json
{"id":"CMC-2025-PRE-NonMathB-I-1","status":"adjudicated","review_type":"human","reviewer_ids":["reviewer-a","reviewer-b"],"response_sha256":"填写真实回答UTF-8文本的64位SHA256","criteria":{"c1":2,"c2":2},"fully_correct":true,"critical_error":false,"rationale":"填写逐点审阅依据及分歧处理"}
```

此示例的哈希占位符不能提交给汇总程序。其他题的评分点键和权重以题库记录为准。原始回答文本及其哈希必须保留在实验目录，汇总器检查哈希格式；它不会替你完成回答文本与哈希的外部归档核对。

## 指标

- **完整正确率**：4分且无严重错误的题数 / 固定题数；附 Wilson 95% 区间。
- **归一化得分**：逐题得分 / 4 后取平均，各题等权。
- **难度宏平均**：L1–L8完整正确率的等权平均；同时列出各层真实题数。缺少某层时指标为空，不虚填0或重分配权重。
- **四个粗层**：每相邻两级合并，报告各粗层题数、正确率及归一化得分。
- **能力评分点得分**：某能力所有评分点实得分 / 这些评分点总分，附涉及题数。五维有重叠，不能把它们当作五个独立统计检验。
- **成对方法差异**：同题比较正确率差，用独立题目为重采样单位做配对 bootstrap；若后续一题族有多个变体，应改用题族为重采样单位。
- **成本**：实际模型调用、总token、工具调用、时间及运行失败。成本必须来自运行日志，汇总器不伪造这些数值。

小样本限制：测试集82题，L8仅1题。细分八级须同时报告样本数与L1–L2、L3–L4、L5–L6、L7–L8四个粗层得分，不能把一个高阶题的胜负解读为稳定排序。置信区间与效应大小比一次胜负更重要；学科严重不均衡，当前整体分数主要反映分析类能力。

## 迁移能力的额外实验

当前36题的迁移标签表示“把方法用于新表示/新结构”的可观察证据，不是已证实的跨分布迁移。若要声称迁移提升，需另建协议：

1. 为每个目标题族定义允许学习的源任务和关键方法，并在运行前冻结；同题换数字或翻译不能作为独立目标题。
2. 将同构题、解法近重复题及带方法提示的版本同族隔离。源材料与目标条件、结论应有明确结构差异。
3. 用同一模型随机分配“有相关源材料”“无源材料”及“等长度无关材料”条件，在匹配预算下测试。
4. 由盲评证明目标推导正确，报告目标正确率差、成本与污染审计；题族/模型数量不足时不做强结论。

这些配对材料与真实实验**尚未制作或执行**，不能从本版能力标签反推已经测过迁移。
